# ゲーム内イベントについて
Domain層が他クラスにイベントを通知したい
そう思ったことありませんか？

## GameEvents.h
コンストラクタでプレイヤーとエネミーがこのクラスをもらいます
何かイベントを起こしたいとき定義されているイベントをQueueに追加(push)します

## UseCase/GameEventHandler.h
イベントの発生をQueueから受け取り、それぞれのイベント管理クラスに通知します
PlayerDamagedEventならhandlePlayerDamagedEvent関数を呼び、その中でそれぞれの管理クラスに通知します
PlayerDamagedEvent =>handlePlayerDamagedEvent => CameraEvent.CameraShakeなど

## CameraEvent.h
カメラのイベントを構造体として定義して、Queueを管理します
このQueueをCameraServiceが取り出してCameraの描画処理であるCameraManagerに処理を渡します
