## 音関連

### 実装方法
音を `enum class Sound` で定義し、`init` に入れて使用したいところでインスタンス経由で呼び出す:

```cpp
Jam::Presentation::AudioService::get().playOneShot(
    Jam::Presentation::AudioService::Sound::SE_Explosion, 
    0.5
);
```
