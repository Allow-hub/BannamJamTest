##  ゲーム紹介
「シン層シン理地雷ちゃん」は、
“シン縮自在のチョーカー”を駆使して戦う ワイヤーアクション2Dゲーム です。
プレイヤーは YUMEMIちゃん を操作し、
相棒の リスカちゃん とともに「マイン・ド・ダイブ」の力で人の心を救っていきます。
ステージ内を縦横無尽に駆け回り、敵を倒しながら心の闇を突破せよ！

🎮 操作方法
操作	動作
W / Space	ジャンプ
A / D	左右移動
S	薄い床をすり抜ける
Shift	ダッシュ
左クリック	チョーカーワイヤーを発射
マウス操作	チョーカーの方向を操作
